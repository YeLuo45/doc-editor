# 文档编辑器

一款简洁高效的 Web 富文本编辑器，基于 React + Tiptap 构建。

**访问地址**: https://yeluo45.github.io/doc-editor/
**GitHub 仓库**: https://github.com/YeLuo45/doc-editor

## 功能特性

- 富文本编辑（加粗/斜体/下划线/删除线/标题/列表/引用/代码块/链接/图片）
- 文档管理（侧边栏列表/新建/删除/重命名）
- 自动保存 + 历史版本
- 导出 Markdown / HTML / PDF
- 主题切换（亮/暗）
- 本地化中文

## 技术栈

React 18 + Vite 5 + TypeScript + @tiptap/react + lowlight + i18next + idb
